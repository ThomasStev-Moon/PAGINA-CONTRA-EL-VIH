## 📖 Sobre el Proyecto

Este proyecto nace con el objetivo de **romper el estigma** y brindar información clara, científica y accesible sobre el VIH/SIDA en Colombia. No es solo una página web; es una herramienta de concientización que combina diseño moderno, interactividad y tecnología (como Inteligencia Artificial) para acercar la prevención a los jóvenes y a la comunidad en general.

> 💡 *"El VIH no define a una persona; el respeto y la empatía sí."*

---

## ✨ Características Destacadas

| Módulo | Descripción |
| :--- | :--- |
| 🎠 **Slider Interactivo** | Carrusel automático con las principales campañas de prevención. |
| 📚 **Educación Clara** | Tarjetas informativas sobre PrEP, PEP, mitos y el concepto "Indetectable = Intransmisible". |
| 💬 **Testimonios** | Historias reales de resiliencia para fomentar la empatía y la inclusión. |
| 🖼️ **Galería Lightbox** | Visualización de imágenes ampliadas sin salir de la página. |
| 🏥 **Directorio de Ayuda** | Enlaces directos a fundaciones y entidades de salud en Colombia. |
| 🤖 **Chatbot "InfoVIH"** | Asistente virtual impulsado por IA (DeepSeek) que responde dudas 24/7 de forma confidencial. |
| 📱 **100% Responsivo** | Adaptado para móviles, tablets y computadoras. |
